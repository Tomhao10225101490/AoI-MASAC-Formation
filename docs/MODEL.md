# 模型、算法和这次改过的错误

这篇文档给要写论文和要改代码的人。运行命令在 README。指标的逐列定义在 `docs/METRICS.md`。下面的数字凡是耗时，都是 2026-10-20 这台 4 核 CPU 上的短跑，成功率都是 0，不能写进论文当结果。

## 1. 二维地图现在还能不能发

能。2025–2026 仍然有二维设定被接收：

- Drones，2026-10-11，DI-MATD3：多无人机编队、异步时延、每条链路自己的 AoI，外加由 AoI 决定预测步数的卡尔曼滤波。场景是平面上的双偏置窄门。三个种子、最大时延 0.6 s 时，作者报告 Kalman+AoI 任务成功率 97.33% ± 1.89%，常速度外推 88.67% ± 8.96%，不预测 65.33% ± 29.41%。这些是他们的数字，本仓库没有复现。
- Drones，2025-06，Ali 等人把同一批强化学习算法先放在二维点模型里比，再放进三维物理引擎。二维那一档本身也是正式实验，不是草稿。
- 大量 AoI 数据采集论文仍然把无人机放在固定高度的平面上。

所以“只要是二维就一定被拒”不成立。

编队加障碍这一支，审稿人会拿来对照的工作已经把高度写进状态：

- Xie 等人，arXiv:2410.18495，2025-03 的修订版。静态障碍加动态障碍的编队，注意力观测，课程学习，仿真和真机。正文直接写：从二维走到三维会把探索空间明显放大。
- Drones，2025-12，Multi-Attention Meets Pareto。三维城市，建筑物是有高度的盒子，评论家看邻近建筑的中心和半尺寸。骨干是 MADDPG，作者说同一套前端可以接到 MASAC。
- Park 等人，arXiv:2501.02453，2025-01。建筑物是长方体。视线是否被挡，取决于射线有没有从屋顶上面过去，而不只是地面脚印挡不挡。

只把建筑物画成没有高度的圆盘，就写不出“爬高恢复视线”这个动作。这个动作恰好是通信论文和编队论文的接口，所以地图改成了带屋顶高度的三维，而不是因为二维已经发不出来。

## 2. 算法相对最近的工作多了什么

DI-MATD3 已经做了三件会和“观测里放一个 AoI”撞车的事：每条链路一个时间戳、AoI、以及用 AoI 驱动的卡尔曼均值。它比较了不预测、常速度、卡尔曼。骨干是 MATD3。它没有建筑物，信道是有界时延，不是随机丢包，策略也看不到预测有多不准。

本文留在同一条问题上，增加的是这三件一起出现：

1. 丢包是伯努利的。成功概率随三维距离指数下降；三维线段切到建筑物体积时再乘 `nlos_factor`。爬过屋顶，遮挡消失，概率回到只由距离决定。横穿的飞机是球体，只造成碰撞，不挡无线电。
2. 跟随者在本地跑一个常速度卡尔曼。均值用来摆槽位。三个位置标准差写进观测。预测位置和自己的连线切到已知建筑物时，过程噪声乘 `nlos_q_scale`（默认 4）。转弯绕楼的时候，常速度模型最不可信，标准差就在这个时候变大。
3. 骨干用 MASAC，而不是确定性的 MATD3。信道是随机的，策略带熵，比在时延上加一点探索噪声更贴这个随机性。更新公式本身是标准的集中式双 Q 软演员-评论家，没有再发明一个新的策略梯度。

要证的行为是：消息变旧、而且预测方差变大的时候，僚机是爬高去恢复视线，还是贴着过期槽位从楼侧面挤过去。奖励里没有“请把 AoI 变小”这一项。高度误差会算进编队误差，所以爬高是有代价的。

## 3. 运动

外环，假定里面已有飞控。动作 `(a_v, a_ω, a_z)` 都在 [-1, 1]。

```
加速度     = a_v * max_accel         默认 6 m/s²
偏航速率   = a_ω * max_yaw_rate      默认 1.2 rad/s
垂直加速度 = a_z * max_climb_accel   默认 3 m/s²

v       ← clip(v + 加速度 * dt, 0, 16 m/s)
heading ← wrap(heading + 偏航速率 * dt)
vz      ← clip(vz + 垂直加速度 * dt, -6, 6 m/s)

x ← x + (v * cos(heading) + wind_x) * dt
y ← y + (v * sin(heading) + wind_y) * dt
z ← z + vz * dt
```

`dt = 0.2` s。高度限制默认 15 m 到 120 m，巡航高度 40 m。风每个回合抽一次，速率 0 到 4 m/s，只加在水平地速上。演员看到的是带噪声的风估计；评论家看真实风。

以 16 m/s 平飞、偏航顶满，转弯半径大约 `v / yaw_rate ≈ 13` m，和楼的半径同一量级，不能原地甩头。垂直方向顶满也要好几步才能翻过一座 50 m 的楼。

出界会被夹回地图或高度带内，该机得一个小惩罚，回合不因此结束。

## 4. 编队和航路

楔形写在领导者机体坐标，间距 32 m。+x 是机头，+y 是左，高度偏移是 0：

```
第 1 排: (-32, -24, 0) 和 (-32, +24, 0)
第 2 排: (-64, -48, 0) 和 (-64, +48, 0)
```

世界坐标把水平偏移按航向旋转，高度直接加上领导者高度。奖励用真实位姿。观测里的槽位用这架僚机被允许使用的位姿。两套位姿可以不一样。

航路点（米）在 `envs/scenario.py`：

| 序号 | x | y | z | 这一段上的楼 |
|---|---|---|---|---|
| 1 | 280 | 420 | 40 | |
| 2 | 520 | 560 | 80 | 第一段中点附近，半径 36 m，高 50 m，可以飞越 |
| 3 | 800 | 320 | 40 | 第二段中点附近，半径 34 m，高 160 m，高过 120 m 的升限，必须绕 |
| 4 | 1080 | 500 | 40 | 第三段中点附近，半径 32 m，高 70 m，巡航高度会撞，爬高可以过 |

另外 5 栋楼不压在航段上，高度从 40 m 到 110 m。3 个交通球体速度大约 4–8 m/s，高度大约 35–60 m，碰到边界就反向。

领导者从大约 (150, 420, 40) 出发，速度 10 m/s，朝 +x。进入航路点球（半径 30 m）就捕获，然后转向下一个点。最后一个点还要求全队进入 `formation_tol`（18 m）。

## 5. 碰撞

建筑物，高度 `height > 0`，立在地面上：

- 飞机在屋顶以下：水平间隙 = 水平距离 − 楼半径 − 机身半径。负的就是撞上。
- 飞机在脚印里、人已经高于屋顶：间隙改成 `z − height − 机身半径`。正的就是从屋顶上面过去了。
- 人在脚印外面：用水平间隙，和高度无关。

交通球体：三维距离 − 两半径。两架飞机：三维中心距离小于 `2 * 机身半径`（8 m）算互撞。上下错开 40 m、水平重叠，不算撞。

## 6. 信道

只有领导者到跟随者这一条链路会丢包。每个跟随者、每一步独立抽一次。

先判几何。对每栋 `blocks_radio` 的楼，看三维线段是否切到竖直圆柱（半径可加 `blockage_margin`，默认 0）。圆柱从 z = 0 伸到 `height`。线段在脚印里的那一段，高度的最低点仍低于屋顶，才算非视距。两端都在屋顶以上时，整段都在屋顶以上，不算挡。实现在 `envs/geometry.py` 的 `segment_hits_vertical_cylinder`。

然后

```
distance 模式:
    p = p0 * exp(-d / d0)          d 是三维距离
    若这一跳几何上被挡，且 use_blockage 为真:  p ← p * nlos_factor

independent 模式:
    p = p0                         距离和楼都不看。扫描图的横轴用这个。

perfect 模式:
    p = 1
```

默认 `p0 = 0.95`，`d0 = 200` m，`nlos_factor = 0.2`。训练时每个回合把 `p0` 抽成 Uniform[0.45, 1]，除非模式是 perfect，或这一回合的 options 里写死了 `p0`。

例子：`p0 = 1`，`d0 = 200`，距离 0 时 p = 1；距离 200 m 时 p ≈ 0.37；再被楼挡住就变成约 0.074。两机都爬到屋顶以上之后，遮挡项回到 1，p 回到只由距离决定的那个数。

AoI 从 0 开始。收到包归零，没收到就 +1，上限 40。回合开始时的那一次同步不计入链路成功率。

`nlos_fraction` 记的是几何遮挡，不管 `use_blockage` 开没开。评论家观测里的遮挡位只在 `use_blockage` 为真时才是 1，免得“楼不挡无线电”这个消融被评论家偷偷用回去。

## 7. 信念

每个跟随者维护领导者的空气速度状态

```
μ = [x, y, z, vx, vy, vz]
```

收到包时：

```
vx = v * cos(heading)
vy = v * sin(heading)
μ ← 测量
P ← diag(测量方差)     位置方差默认 1 m²，速度方差默认 0.25 (m/s)²
AoI ← 0
```

没收到包时先推均值，风用的是这一步的噪声风估计，不是真实风：

```
x ← x + (vx + wind_obs_x) * dt
y ← y + (vy + wind_obs_y) * dt
z ← z + vz * dt
```

再用推完的位置和跟随者自己的位置，对已知建筑地图做一次遮挡检测。切到楼则 `q_scale = nlos_q_scale`，否则为 1。协方差

```
P ← F P Fᵀ + q_scale * Q
```

`F` 是上面的常速度矩阵。`Q` 对角，位置过程方差默认 0.25，速度过程方差默认 1。协方差元素截断在 ±22500（对应 150 m 的标准差）。观测里放的是 `sqrt(P_xx), sqrt(P_yy), sqrt(P_zz)`，再除以 `std_scale`（80 m）。

建筑地图对滤波器是已知的（城市底图）。动态交通不在这张图里。演员的障碍感知仍然受 `sensor_range`（250 m）限制，这和滤波器用的底图不是同一路信息。

航向不进卡尔曼状态。槽位的朝向用最后一次测量的航向。速度标量用 `hypot(vx, vy)`。

## 8. 观测模式

同一套网络，差别只在环境往观测里写什么。

| `obs_mode` | 槽位用的领导者 | AoI 通道 | 标准差通道 | 谁在用 |
|---|---|---|---|---|
| `belief` | 卡尔曼均值 | 开 | 开 | 本文方法 `belief_masac` |
| `belief_point` | 卡尔曼均值 | 开 | 强制为 0 | 消融：只给均值，不给不确定性 |
| `aoi` | 上一包的测量，不外推 | 开 | 强制为 0 | 对应 DI-MATD3 的“不预测，只给年龄” |
| `extrapolate` | 卡尔曼均值 | 强制为 0 | 强制为 0 | 对应常速度外推 |
| `hold` | 上一包测量 | 强制为 0 | 强制为 0 | 丢了就停在上一包 |
| `perfect` | 真实位姿 | 强制为 0 | 强制为 0 | 理想通信训练 |

`use_aoi: false` 再把 `aoi` / `belief` / `belief_point` 的年龄通道清零。

完美链路训练出来的策略，拿到 `p0 < 1` 的测试链路时，评估脚本会自动改成 `hold`。否则网络拿到的仍是真实领导者，丢包没有意义。要看理想通信下的上限，显式传 `--obs-mode perfect`。

本地观测前 34 维，然后每个最近障碍 9 维。默认看 3 个障碍，观测长度 61。评论家全局状态默认 182 维：5 架飞机 × 7，加风、航路进度、4 个航路点 × 3、11 个障碍槽 × 8、4 条链路 × 11。改跟随者数量、障碍槽数量或航路点槽数量，旧检查点对不上。

障碍的 9 维是：相对 x、相对 y、屋顶（或球体中心）相对高度、三轴速度、半径、楼高、是否在感知距离内。楼用到脚印的水平距离来决定看不看得见，所以脚底下的屋顶不会因为“中心在脚下、三维距离很短”以外的原因被丢掉，也不会因为人已经飞高就看不见这栋楼。

## 9. 奖励

领导者，针对**捕获前**的那个航路点：

```
w_progress * (上一步距离 − 这一步距离)
+ w_heading * cos(方位角 − 航向)
− w_smooth * ||动作||²
− w_step
```

距离是三维的。捕获发生的那一步，距离差只对当前这个点计算。先把索引拨到下一个点再算差，会把“下一点还很远”记成一大笔负进度，把航路点奖金抵消掉。这个错误已经修掉，并有测试钉住。

跟随者：

```
w_form_progress * (上一步误差 − 这一步误差)
− w_formation * 误差
+ w_heading * cos(领导者航向 − 自己的航向)
+ 误差 ≤ formation_tol 时的 formation_bonus
− w_smooth * ||动作||²
− w_step
```

误差是到真实槽位的三维距离，所以爬离领导者的高度会被记进误差。

间隙小于 `clearance_margin`（20 m）时，该机再减 `w_clearance * (margin − gap) / margin`。捕获一个点，全队加 `wp_bonus`。成功全队加 `success_bonus`。碰撞全队减 `collision_penalty`。出界只罚出界的那一架。

默认权重是按 0.2 s、16 m/s 的尺度放的起点，没有调过。短跑成功率是 0。

## 10. 学习算法

CTDE，离策略，PyTorch。

- 每个演员只看自己的观测。SAC 演员是 tanh 压缩的高斯，目标熵是 −动作维数，现在是 −3。
- 每个评论家看全局状态和**所有**飞机的动作。SAC 和 MATD3 用双 Q 的较小值。MADDPG 用单个 Q。
- 更新演员 i 时，只把联合动作里的第 i 段换成新样本，其余队友保持回放里的动作。
- 成功和碰撞是终止，不自举。超时是截断，要自举。`train.py` 放进回放的是 `terminated`，不是 `truncated`。
- MATD3 延迟演员和目标网络，目标动作加截断噪声。MADDPG 把 `policy_delay` 固定成 1。
- SAC 的探索来自熵。`ou_episodes` 默认 0。

MAPPO 在 `algos/mappo.py` 里构造时抛 `NotImplementedError`。不要报它的数。

## 11. 这次修过的实现错误

这些都会改变训练信号，不单是文档和地图。

1. 捕获航路点的同一步，进度奖励曾经改用到**下一个**点的距离。点与点相距一两百米时，这一步的进度是很大的负数，`wp_bonus` 补不回来。现在进度在拨索引之前就算完。
2. 最后一个航路点曾经在领导者进球的瞬间就捕获。队形可以过一会儿、在别的地方收拢，然后被记成成功。现在最后一个点要等全队进入 `formation_tol`。
3. 外推曾经只用空速，不加风。侧风会把真实轨迹和槽位系统地错开。现在均值推进使用这一步的风估计。真实风仍然只作用在动力学和评论家上。
4. 风估计的噪声以前写在 `_observations` 里面。同一步把观测读两遍，风和信念都会变。现在每个回合、每一步只抽一次，存在环境里。
5. 碰撞和遮挡以前都是平面圆盘。高度不能救碰撞，也不能恢复视线。交通圆盘还会挡无线电。现在楼是有限高的圆柱，交通是球体且 `blocks_radio` 为假。
6. 机间碰撞以前只看水平距离。上下错开仍会被判撞。现在用三维距离。

滤波器、双 Q、终止自举这几处对过测试，没有发现会把梯度算错的错误。奖励权重没有调，所以短跑学不会，这不是实现错误。

## 12. 还没做、也不要假装做了的

- 没有把 DI-MATD3 的 97% 复现出来。场景不同，数字不能搬。
- 没有六自由度旋翼、没有桨、没有能耗、没有菲涅尔区。遮挡是线段切圆柱。
- 没有事件触发通信。ET-MATD3（2026）学的是什么时候发包。本文的链路每步都尝试一次，失败是信道造成的，不是策略选择不发。
- 没有安全层或控制障碍函数。2025 年的安全编队工作用 CBF 去改不安全动作。本文的碰撞只进奖励和终止。
- MAPPO 没有实现。没有 GPU 计时。没有多种子的论文曲线。
