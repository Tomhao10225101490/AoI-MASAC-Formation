# 指标定义

训练和评估写进 CSV 的每一个数，都按下面的定义计算。画图脚本读的就是这些列名，不要改名。

一个回合只会计入下面三类结局中的恰好一类：成功、碰撞、超时。

## 回合是怎么结束的

符号：跟随者 \(i\) 到**真实**编队槽位的距离是 \(e_i\)。槽位由真实领导者的位置和航向，加上该机在楔形编队里的偏移算出来。航路点按顺序捕获，领导者进入 `wp_radius` 就算过了一个点。

- **成功**：航路点已经全部捕获，并且这一步每个跟随者都满足 \(e_i \le\) `formation_tol`，并且本回合从开始到现在没有发生过碰撞。只飞过第一个点不算成功。
- **碰撞**：这一步至少有一架飞机撞上障碍物圆盘，或者两架飞机中心距离小于 `2 * uav_radius`。和“刚好完成航路”发生在同一步时，算碰撞，不算成功。
- **超时**：步数达到 `max_steps`，既没有成功也没有碰撞。

碰撞再拆成两列，一个回合可以两列都是 1：

- `obstacle_collision`：有飞机与圆形障碍重叠。
- `inter_uav_collision`：有两架飞机彼此重叠。
- `collision`：上面任一发生则为 1。

## 率是怎么平均的

`summarize_episodes` 做的是**按回合宏平均**：每个回合先算出自己的一个数，再对回合取平均。长回合不会因为步数多就占更大权重。样本标准差用 \(n-1\)（只有 1 个回合时标准差记 0）。

| 汇总名 | 一个回合里怎么算 | 再怎么汇总 |
|---|---|---|
| `success_rate` | 成功记 1，否则 0 | 回合平均 |
| `collision_rate` | 发生过碰撞记 1 | 回合平均 |
| `obstacle_collision_rate` | 发生过障碰记 1 | 回合平均 |
| `inter_uav_collision_rate` | 发生过机间碰撞记 1 | 回合平均 |
| `timeout_rate` | 超时记 1 | 回合平均 |
| `formation_keeping_rate` | 所有跟随者同时满足 \(e_i \le\) `formation_tol` 的步数，除以本回合步数 | 回合平均 |
| `mean_formation_error` | 每一步先对跟随者的 \(e_i\) 取平均（米），再对步取平均 | 回合平均 |
| `mean_aoi` | 每一步、每个跟随者在**抽完包之后**的 AoI 整数，先在本回合里平均 | 回合平均 |
| `max_aoi` | 本回合里出现过的最大 AoI | 回合平均 |
| `packet_success_rate` | 收到的包数 / 尝试的包数。每个跟随者每步尝试 1 次。回合开始时免费同步的那一次**不算** | 回合平均 |
| `mean_outage_length` | 每个跟随者连续丢包的每一段长度（步）。从来没丢过包的飞机不贡献段。一段都没有的回合记 0 | 先在回合内取段的平均，再对回合平均 |
| `mean_return` | 所有飞机回报之和 | 回合平均 |
| `mean_steps` | 回合步数 | 回合平均 |
| `waypoint_fraction` | 已捕获航路点数 / 航路点总数 | 回合平均 |
| `nlos_fraction` | 跟随者到领导者的线段撞上建筑物圆盘的尝试次数 / 尝试次数。这是几何事实，跟 `use_blockage` 开没开无关 | 回合平均 |
| `min_clearance` | 本回合里飞机表面到障碍表面的最小间隙（米），撞进去是负数 | 回合平均 |

编队保持率不是“平均每架飞机有多接近”，而是“这一步是不是**全队**都在槽位里”。失败的回合也算进去，不会只在成功回合上报一个好看的数。

## 和观测有关、但不进表格的约定

- 奖励里的编队误差用**真实**领导者位姿。
- 跟随者观测里的“该去的槽位”只用它**被允许知道**的领导者位姿（全新的、过时的、或线性外推的）。
- AoI 在收到包的那一步归零，没收到就 +1，最大不超过 `aoi_cap`。外推用的“过了几步”也是这个封顶后的数。

## 丢包率扫描图的横轴

`scripts/sweep_packet_loss.py` 把信道临时改成与距离无关的独立丢包，名义丢包率 `loss_rate = 1 - p0`。图上的横轴是这个名义值。`packet_success_rate` 是仿真里真正收到的比例，应当接近 `1 - loss_rate`，可以用来检查随机数没有画错。

这张图回答的是“把丢包率从 0% 调到 70%，编队还剩多少”。它和训练时用的距离相关信道不是同一个分布。比较算法时，每条曲线都要在这条相同的测试信道上测。
