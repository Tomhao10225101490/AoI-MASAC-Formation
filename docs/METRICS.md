# 指标定义

训练和评估写进 CSV 的每一个数，都按下面的定义计算。画图脚本读的就是这些列名，不要改名。

一个回合只会计入下面三类结局中的恰好一类：成功、碰撞、超时。

## 回合是怎么结束的

符号：跟随者 \(i\) 到**真实**编队槽位的三维距离是 \(e_i\)。槽位由真实领导者的位置、高度和航向，加上该机在楔形编队里的水平偏移算出来。编队在高度上是平的：槽位高度等于领导者高度。

航路点是三维球，半径 `wp_radius`。中间的点只要领导者进球就算捕获。**最后一个点**要等所有跟随者都满足 \(e_i \le\) `formation_tol` 才捕获，所以不能先把航路点记完、再在别处把队形收拢就算成功。

- **成功**：航路点已经全部捕获，并且这一步每个跟随者都满足 \(e_i \le\) `formation_tol`，并且本回合从开始到现在没有发生过碰撞。只飞过第一个点不算成功。
- **碰撞**：这一步至少有一架飞机撞上建筑物或横穿球体，或者两架飞机的三维中心距离小于 `2 * uav_radius`。高度差够大就不算机间碰撞。和“刚好完成航路”发生在同一步时，算碰撞，不算成功。
- **超时**：步数达到 `max_steps`，既没有成功也没有碰撞。

建筑物碰撞：飞机在屋顶以下，并且水平距离小于两半径之和。飞机在屋顶以上、人还在脚印里时，看的是离屋顶的垂直间隙，飞过去不算撞。横穿交通是球体，用三维距离。

碰撞再拆成两列，一个回合可以两列都是 1：

- `obstacle_collision`：有飞机与建筑物或交通球体重叠。
- `inter_uav_collision`：有两架飞机彼此重叠（三维）。
- `collision`：上面任一发生则为 1。

## 率是怎么平均的

`summarize_episodes` 做的是**按回合宏平均**：每个回合先算出自己的一个数，再对回合取平均。长回合不会因为步数多就占更大权重。样本标准差用 \(n-1\)（只有 1 个回合时标准差记 0）。

| 汇总名 | 一个回合里怎么算 | 再怎么汇总 |
|---|---|---|
| `success_rate` | 成功记 1，否则 0 | 回合平均 |
| `collision_rate` | 发生过碰撞记 1 | 回合平均 |
| `obstacle_collision_rate` | 发生过障碰记 1 | 回合平均 |
| `inter_uav_collision_rate` | 发生过机间碰撞记 1 | 回合平均 |
| `timeout_rate` | 超时记 1 | 回合平均 |
| `formation_keeping_rate` | 所有跟随者同时满足 \(e_i \le\) `formation_tol` 的步数，除以本回合步数 | 回合平均 |
| `mean_formation_error` | 每一步先对跟随者的 \(e_i\) 取平均（米），再对步取平均 | 回合平均 |
| `mean_aoi` | 每一步、每个跟随者在**抽完包之后**的 AoI 整数，先在本回合里平均 | 回合平均 |
| `max_aoi` | 本回合里出现过的最大 AoI | 回合平均 |
| `packet_success_rate` | 收到的包数 / 尝试的包数。每个跟随者每步尝试 1 次。回合开始时免费同步的那一次**不算** | 回合平均 |
| `mean_outage_length` | 每个跟随者连续丢包的每一段长度（步）。从来没丢过包的飞机不贡献段。一段都没有的回合记 0 | 先在回合内取段的平均，再对回合平均 |
| `mean_return` | 所有飞机回报之和 | 回合平均 |
| `mean_steps` | 回合步数 | 回合平均 |
| `waypoint_fraction` | 已捕获航路点数 / 航路点总数。最后一个点在队形收好之前不算捕获 | 回合平均 |
| `nlos_fraction` | 跟随者到领导者的三维线段切到建筑物体积的尝试次数 / 尝试次数。射线从屋顶上面过去不算。横穿球体不算。这是几何事实，跟 `use_blockage` 开没开无关 | 回合平均 |
| `min_clearance` | 本回合里飞机表面到障碍表面的最小间隙（米），撞进去是负数。建筑物在屋顶以上时用垂直间隙，其余用水平或球体间隙 | 回合平均 |
| `mean_belief_std` | 每一步、每个跟随者在抽完包之后，**槽位**标准差在三个世界轴上的平均（米），再对本回合平均。含航向力臂，不是领队位置标准差本身。列名沿用旧名。保持上一包、只看 AoI 的模式也会跑这个滤波器，所以这一列每种观测都有。演员只有 `belief` 模式读得到它 | 回合平均 |
| `los_mean_formation_error` | 几何视距的跟随者-步上的真实槽位误差（米）。这一侧没有样本则为 NaN | 丢掉 NaN 后对回合平均 |
| `nlos_mean_formation_error` | 几何非视距的跟随者-步上的真实槽位误差（米）。没进楼后的回合是 NaN，不会被当成 0 | 丢掉 NaN 后对回合平均 |
| `los_mean_aoi` / `nlos_mean_aoi` | 同一分割下、抽完包之后的 AoI | 丢掉 NaN 后对回合平均 |
| `los_mean_slot_std` / `nlos_mean_slot_std` | 同一分割下的槽位标准差（米） | 丢掉 NaN 后对回合平均 |
| `los_mean_alt_error` / `nlos_mean_alt_error` | 同一分割下，跟随者到真实平槽位的垂直距离绝对值（米）。这是爬高付出的高度。视距段也很大，说明它离开了编队，不是在楼后买测量 | 丢掉 NaN 后对回合平均 |

编队保持率不是“平均每架飞机有多接近”，而是“这一步是不是**全队**都在槽位里”。失败的回合也算进去，不会只在成功回合上报一个好看的数。

## 和观测有关、但不进表格的约定

- 奖励里的编队误差用**真实**领导者位姿。
- 跟随者观测里的“该去的槽位”只用它**被允许知道**的领导者位姿：真实位姿、上一包测量、或常速度外推。`belief` 模式还会给出槽位标准差，不是领队位置标准差。
- AoI 在收到包的那一步归零，没收到就 +1，最大不超过 `aoi_cap`。
- 捕获一个航路点时，进度奖励只用“对当前这个点又靠近了多少”。不会把切换到下一个点造成的距离跳变记成负的进度。

## 丢包率扫描图的横轴

主图是 `scripts/sweep_geometry.py`。信道保持距离乘遮挡，横轴是 `p0`。表里要同时看视距和非视距的编队误差，以及 `los_mean_alt_error` 和 `nlos_mean_alt_error`。方法如果有用，高度代价的差别出现在非视距列，视距列保持小。全程平均会把这件事抹平。

动机图不经过策略：`scripts/motivate_slot_std.py` 把默认信道和滤波器跑出来，说明 40 m 视距平均只丢 0.29 个包，屋顶挡住则丢 5.43 个，连丢 6 步后槽位标准差的最大轴到 11 m（楼后再放大过程噪声则到 22 m），领队位置标准差只有约 2 m。这张图可以写进论文，但必须标明没有训练。

`scripts/sweep_packet_loss.py` 把信道临时改成与距离无关的独立丢包，名义丢包率 `loss_rate = 1 - p0`。图上的横轴是这个名义值。`packet_success_rate` 是仿真里真正收到的比例，应当接近 `1 - loss_rate`，可以用来检查随机数没有画错。这是压力测试。它和训练时用的距离相关信道不是同一个分布。`scripts/run_key_experiment.sh` 先跑几何扫描，再跑这一条。
