# V3 300k：离线 SAC 目标、TD 误差和 Critic 梯度审计

2026-11-03。此协议在读取 300k Replay 抽样结果前固定。用途是诊断已完成的两个 Standard MASAC 训练历史，不进行训练、参数更新、策略选择或机制对照，也不证明高梯度是导航失败的原因。

## 样本与抽样

只使用 `results/masac_v3_paired_300k_20261103` 中 `curriculum` 和 `original` 两个历史、各训练种子 411/422/433 的 `snapshots/300000` 完整 checkpoint 与对齐 Replay。检查六分支批次的完成/错误标志、快照 `complete.json` 及 checkpoint、Replay、协议 SHA-256、步数/种子/容量/环形指针，核对执行时 Actor/Critic 源码与训练快照；失败即停止。样本来自每次训练最后 100,000 个联合 transition。课程组原先前 30,000 步短程经验已由 FIFO 替换，本轮 300k Replay 包含的都是后续完整任务经验；训练种子之间独立，同一 Replay 内的 transition 相关。

分别用 Replay 保存的 `done` 分为终止和非终止两层。每层从全体索引中**不放回**抽取最多 512 条；若该层不足 512 条，则使用该层全部样本。记录每层总体大小、样本量与所占总体频率，不把平衡抽样的比例当作真实发生频率。每个训练历史/种子使用 NumPy `default_rng`，抽样种子为 `20261103 + seed + offset`，课程 offset 为 10,000，原始 offset 为 20,000，固定先抽非终止层、再抽终止层。

按照 `structured.py` 和运行器，`done` 是碰撞或全队成功的终止标志；到 350 步截断单独返回，训练 Replay 只写 `done`，截断本身继续 bootstrap。终止与截断也可能同一步发生。Replay 不保存碰撞类型或独立截断标记，故不能仅据 `done` 区分终止原因，也不能据 `done=0` 推断非截断。已结束回合零成功是另一个基于日志的描述，不修改这一定义。

## 一步目标与梯度

CPU、单线程，载入保存的 Actor、target 双 Q、在线双 Q 和 `logalpha`，保持参数原值。每层计算前独立 `torch.manual_seed(987654321 + seed + offset + done)`；Actor 对下一观测采样一次，依照实际训练代码计算

`target = r + 0.99 * (1 - done) * (min(Q1_target,Q2_target) - exp(logalpha) * mean_team_log_prob)`。

`done=1` 的 bootstrap 因子为零；所有目标和Actor动作在 `no_grad` 中计算，不回传 Actor、target 或 alpha。在线双 Q 的损失为两项各自 batch mean MSE 的和。分别记录 r、目标、bootstrap、Q1/Q2、目标减Q的带符号与绝对 TD 误差分布，以及目标动作熵项。仅对在线两个 Critic 执行 backward，记录全参数合并、单Q梯度范数；**不裁剪、不调用任何 optimizer.step、不修改 checkpoint、Replay 或训练源码**。原训练阈值5仅用来解释假设采样批次的裁剪比例。

记录每层自身平均损失梯度 `g0`、`g1`，及按总体频率 `w0=N0/N`、`w1=N1/N` 加权的 `w0*g0`、`w1*g1` 和总和的范数与两层梯度余弦；向量可能抵消，范数不是可相加的因果贡献。总体目标/绝对TD等均值按相同总体频率加权估计，并分别保留层内值。每个样本只采一次下一动作，结果受固定样本和动作采样影响，不能解释成所有更新的真实梯度。

## 目标附近分组与限制

从每条 transition 的动作前观测 `obs[..., :3] * 240` 还原三机目标相对向量，按**任一单机**距自身目标是否小于 50 米，将每层样本再分近/远组；记录个数、Q/目标/TD绝对值及组内 MSE 梯度范数。另计任一单机距离<4米且速度<2m/s的观测数；这不是全队成功，也不是独立回合。近/远组的 TD 和梯度仅在对应抽样量上描述，终止层极少样本、组间分布及相关性均可能导致不稳定；零样本组应显示为空，不能默默删分母。

保存协议、审计脚本、源代码、每个 checkpoint/Replay 的 SHA-256，抽样种子、样本索引哈希、随机动作种子、每层总体数和样本数，以及 NumPy/PyTorch 版本、完整结果。全部文件写到独立新路径，不覆盖既有证据。以重跑完全一致和小型独立公式/权重校验作为实现检查；最终仍是离线相关性诊断，不能据此单独断定是否应改学习率、奖励或梯度阈值。
