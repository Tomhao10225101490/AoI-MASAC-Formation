# V4 前置诊断：V3 Standard MASAC 的 Critic 终止样本覆盖

2026-11-03。此协议冻结于实现和试验前。两组均是 V3 Standard MASAC 的隔离优化诊断，**不是 V4 新网络或机动性候选方法验证**。已完成配对 300k 批次六个训练历史固定开发图均 0/6；用户授权先检查原因、完成标准基线的学习诊断。现有原始历史三个种子的最终完整 checkpoint、Replay 和进行中的环境/回合均保留，所有新输出使用独立目录。

## 背景、假设与限制

`docs/MASAC_V3_PAIRED_300K_RESULTS_20261103.md` 和 `results/masac_v3_paired_300k_20261103/td_gradient_audit_v2.json` 记录：六组最终 Replay 中 `done=1` 为 0.271%–0.392%；原训练以放回方式均匀采样 128 条时，固定这六个 Replay 分布计算，不含终止样本的理论概率约 60.5%–70.7%。离线一次固定采样下终止层 TD 与梯度大于非终止层；相关状态和训练中会变化的 Replay 分布限制推断。可证伪假设：**提高 Critic 批次对终止 transition 的覆盖，同时按 Replay 真实频率重要性加权，可能改变 Critic 终止状态的拟合和后续导航学习**。目前无训练证据表明该策略有效。

## 严格控制的两组

两组均从 `results/masac_v3_paired_300k_20261103/original_<seed>/snapshots/300000` 各自完整 checkpoint、Replay 和进行中环境/回合恢复，同一种子在 A/B 中叉出同一个起点。两组都引入相同的独立 Critic 批次和 Actor/alpha 批次基础设施；与历史 V3 共用单一批次的更新轨迹不再相同，禁止将本试验归因为纯粹继续历史随机流。

- A `uniform`：Critic 以 Replay 原分布均匀有放回抽取 128 条，权重均为 1。
- B `stratified`：在两个层均非空且 Replay 总数足够时，Critic 目标从 `done=1` 中无放回抽 32 条，从 `done=0` 中无放回抽 96 条。若某层数量不足配额，取该层全部并由另一层补满，记录实际配额；若任一层为空或总体不足 128，则退回 A 的均匀有放回采样。记总体该层比例为 `p_h=N_h/N`、实际采样比例 `q_h=n_h/128`，该层每个样本权重 `p_h/q_h`。双 Q 损失分别为 `mean(weight_i*(Q_i-target_i)^2)` 后相加；分层无放回时，此估计对固定 Replay 的总体均匀 MSE 与**裁剪前**梯度无偏。非线性梯度裁剪及 Adam 意味着裁剪后的更新不保证无偏或路径等价。

两组 Actor 与 alpha 使用各自独立的同规则均匀有放回 128 条批次；共享该 Actor/alpha 批次，Critic target 使用另一个 Critic 批次。Critic 目标完全保持 V3 公式与单次下一动作采样：`r+.99*(1-done)*(min(target_Q1,target_Q2)-alpha*mean_agent_logprob)`，目标 `no_grad`、在线 Q 两项 MSE、Actor `alpha*mean_logprob-min(Q1,Q2)`、现有温度目标、梯度阈值 5、Adam 学习率 3e-4、Polyak .005、1 环境步/更新均不变。`done` 是碰撞或全队成功；350 步纯截断继续 bootstrap；不把 done 称为碰撞类型或将时限问题混入本实验。奖励、地图、三机、运动学、碰撞、网络容量/结构、Replay FIFO 容量 100k、环境重置和全队成功定义均沿用各自原历史。

各 seed 的四个新采样随机流均用 `104729*seed + offset` 初始化，A/B 使用相同种子的相同流初始状态：Critic NumPy offset 31001、Actor NumPy 31002、Critic target Torch 31003、Actor 更新 Torch 31004。环境 rollout 继续恢复父 checkpoint 的 Torch、Python、NumPy、Replay 和探索随机状态；Actor/alpha、Critic目标动作采样流相互独立，B 的分层抽样不消耗 Actor/alpha 的 NumPy 或 Torch 流。A/B 训练后状态可自然分叉，不应声称轨迹始终逐步相同。每次覆盖 Replay 环形槽位同步维护准确的 done 索引；索引顺序和随机流属于恢复状态的一部分，保存并校验以免恢复后抽样改变。

## 预算、评估与输出

固定 3 个独立训练种子 411/422/433；两臂每种子从原 300,000 步续 20,000 环境步，总计新增 120,000 联合环境步与 120,000 次 SAC 更新，每条总步数 320,000、总更新 319,000，无新暖身。这是小规模学习诊断，不是 L0 达标证据或大预算确认试验。所有异常、失败与种子均保留，不能根据最佳中间检查点挑结果。

每 2,000 步分别用完整 V3 地图生成器对原开发图 800001–800006 及新冻结开发图 820001–820006 做确定性 Actor 评估，各组按 urban/warehouse/courtyard 顺序轮换；这些新图也用于开发，不是最终确认测试集。训练 map seed 规则与父历史相同。评估记录联合成功、即时单机捕获、静态/动态/机间/边界碰撞标记、超时、每机最近/最终目标距离、路径、速度及真实轨迹。碰撞标记允许重叠，失败路径不当作成功效率。地图回合不是独立训练种子，最终比较使用每训练 seed 的 320k 检查点。

每 100 环境步记录日志和状态：实验、臂、seed、步数、训练回合、当前真实终止总体比例、Critic 实际采样比例和重要性权重、TD/Q、Actor/Critic loss、alpha、策略entropy、梯度裁剪前后范数和本窗口裁剪频率、评估步数/结果、采样/前向反向/总体速度和ETA。写入 run manifest、冻结协议/源码快照及SHA、JSONL、终端日志、错误/完成标记。记录 Critic 双批次额外采样、计算与吞吐量，A/B均用同样计时方式；不把 CPU/MPS 点测算成学习性能。

每 10,000 新增步和最终 20,000 新增步保存对齐的模型、双 Q/目标、全部优化器、温度、Replay、环形索引、层索引顺序、独立采样器随机流、Torch随机流、环境/当前回合与原父随机流；验证哈希后再标记完整。重复启动由共享训练锁和独占新目录阻止；烟测采用独立输出并标记为烟测，不更新正式活动指针。出错写错误标记，绝不把单臂或分片结果称为六分支完成。

本机可用 MPS；对真实 original/411 300k checkpoint 和固定 Replay 的工程测量（每设备/臂独立进程，预热 50 次、计时 100 次，含环境步和双批次更新、每步同步 MPS，未计 Replay 写入）中，CPU 均匀/分层约 53.91/53.18 步每秒，MPS 约 25.96/25.47 步每秒。它是短时、可能受并发/温度影响的吞吐点测，不是学习效果；`results/masac_v4_critic_sampling_device_benchmark_20261103.json` 保存源码/父数据哈希、RSS和设备分配。当前先固定 CPU，用于保持父批 rollout RNG 的精确恢复与更高实测吞吐；MPS 是独立工程可选路径，不作为本轮正式设备。

实施前先核验父批完成、无 error、每个原始 seed 的 300k 完整快照/Replay 与源码哈希、随机状态及已有训练锁；先执行分层抽样无偏性、极端分层/退化、采样器和物理状态精确恢复、两组批次隔离等必要测试，再做实际短烟测。不得直接启动百万步训练，Critic诊断与新L0任务评估、V4网络或奖励改动分开；未建立可复现的标准导航能力前不启动机动性候选训练。

机器可读配置：`configs/masac_v4/critic_sampling_diagnostic.json`。指标、模型和地图源码均需随每次结果快照固定。结论以实际保存的数据为准。
