# V4 network engineering record — 2026-11-03

This is initialized-network engineering validation, not a training outcome or evidence of navigation, performance, safety or novelty. The frozen research gate still controls any Attention or maneuverability experiment.

## Implementation and explicit assumptions

`v4_networks.py` leaves V3 `Actor`/`TeamQ` unchanged and exposes them as `LegacyActor`/`LegacyTeamQ`. The 162D adapter uses 5 peer, 8 box and 4 moving-object slots; the direct API accepts any object count including zero and masks padding before encoding. Relative positions and box half-sizes are divided by `max(world)` (240 m only in the default world). Velocities are divided by observed `vmax`, and moving radii by 10. Unlike the V3 adapter, the direct API is not limited to 17 slots. An empty or all-masked object set has zero pooled features. Invalid padded values cannot affect output.

All V4 actors and critics include the 11→64→64 risk encoder and a 512-dimensional fused input (384 set + 128 risk) even when the risk input is zero. The same type-shared attention or pool set encoder is replicated independently in each Q. Q1, Q2 and target copies do not share tensors. Tanh action log probability is computed before the environment's radial action projection; it is not the density of the executed physical acceleration.

For exactly matched controls, the two attention blocks each have 132,480 parameters: 128-wide 4-head attention, 128→256→128 feedforward, and two layer norms. Each pool control block uses a token-wise 128→512→128 residual and three 128-dimensional layer norms, also 132,480 parameters. This matches parameter count exactly; the controls still differ in computation and normalization, so the comparison is not an isolated computational-cost comparison.

`v4_prediction.py` accepts only the current 162D observation and public world/radius/margin/timing constants. It never accepts an environment or full-map object. It simulates 19 control directions, including zero, for 2 seconds in 0.2-second increments, with speed-clipped dynamics and constant-velocity peers and moving obstacles. Current visible AABBs, not global geometry, are used. Missing objects have a +40 m capped clearance. TTC is based on sampled nonpositive clearance; braking reserve is initial minimum clearance minus the current-speed braking-distance surrogate; the final binary flag means all sampled minimum clearances are positive. Static-only sets dynamic and peer feature channels to zero, and excludes them from TTC/reserve. Shuffle holds direction columns fixed and independently permutes the eight risk values. Mismatch scales assumed `amax` by 0.5; this is a negative control, not a calibrated prediction model. These sampled local margins do not certify collision-free continuous trajectories or joint feasibility.

## Saved performance

The reproducible source-hashed [engineering profile](../../results/masac_v4_engineering_profile_verified_20261103.json) uses batch 8, three agents, 17 object slots, 19 probes and one CPU thread. It profiles initialized random networks with synthetic tensors. FLOPs are 2× linear/attention matrix multiply-accumulates only; softmax, normalization, activation and backwards are excluded. Memory fields are parameter/gradient/Adam estimates and a sum of hooked-operation output sizes, not measured peak memory. Adam timing is a synthetic combined forward/backward/step microbenchmark, not a real MASAC update. MPS was available on this Mac. The result file records individual CPU and MPS timings.

Each V4 actor has **506,054** parameters; each independent Q pair has **1,273,730**, exactly equal for attention and matching pool. FP32 actor + twin-Q parameters occupy 7,119,136 bytes; a twin target adds 5,094,920 bytes. Estimated raw 100k replay storage for observations, next observations, actions, scalar reward and done is 393,200,000 bytes, excluding metadata and implementation overhead.

A deterministic 2×3 CPU/MPS check using seed 11, one visible box and nonzero velocity gave max absolute actor action differences 6.12e-10 (pool) and 1.05e-9 (attention), and risk feature difference 0, on this installation. This is one small-input check, not a device-wide equivalence guarantee. Device-dependent random-number streams need not match; compare deterministic outputs with a tolerance rather than requiring bitwise stochastic action equality.

Tests in `tests/test_masac_v4_networks.py` cover padding and arbitrary object order, zero objects, mask contamination, agent permutation, independent critics, actor gradients, exact parameter equality, observation-only scope, feature controls, public world geometry, initial collision and candidate perturbations. The test result is implementation evidence only.
