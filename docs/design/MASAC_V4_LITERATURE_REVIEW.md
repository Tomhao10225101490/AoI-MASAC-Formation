# MASAC V4 文献复核与候选方法边界

检索日期：2026-11-03。研究范围仍是 MASAC 多无人机三维独立目标路径规划。本文仅记录查到的研究和本项目可检验的差异，不证明候选方法新颖或有效。V3 两条 Standard 历史各三个种子训练至 300,000 步，最终开发验证均为 0/6；候选机制尚无本项目学习效果证据。

## 1. 用户指定的近年研究

### GDC-MASAC — Wang、Liu、Li，Scientific Reports，2026

**来源与等级：** [出版社页面与摘要](https://www.nature.com/articles/s41598-026-76140-5)，DOI [10.1038/s41598-026-76140-5](https://doi.org/10.1038/s41598-026-76140-5)。出版社显示为 2026-10-16 提前公开的可引用版本，后续可能替换为正式版本；本次重开页面受身份重定向阻止，以出版社可检索摘要为准，**出版社摘要级**。

- **任务与机制：** 在障碍环境中联合考虑多机导航、避障和编队。使用 RRT* 给领机参考航点；将导航、编队和安全分别交给三个解耦 Critic 分支；靠近障碍时调整编队奖励。摘要报告不同障碍密度与群体规模的实验。
- **网络与场景边界：** 目前仅核实三个目标分支的描述；Critic 详细输入/层数、是否采用 twin Q、动态模型、完整三维设置、训练种子及具体代码均未依据正文核验。摘要所报数值不能直接与本仓库开发图相比较。
- **与 V4 的区别：** 本项目任务是独立目标、三维加速度动作；候选是有限控制探针的局部风险观测。RRT* 航点、多个 Critic 分支、编队奖励及仅用 MASAC 本身都已有先例，也不属于本项目候选创新。参考规划器只能作为可观测性受控的对照/验证工具，不可向 Actor 偷渡完整地图真值。

### MATRS — Ge 等，Sensors，2025

**来源与等级：** [出版社论文](https://www.mdpi.com/1424-8220/25/24/7463)，[PubMed 元数据](https://pubmed.ncbi.nlm.nih.gov/41471458/)，DOI [10.3390/s25247463](https://doi.org/10.3390/s25247463)。已查模型、CTDE、Critic 和仿真配置的出版社索引方法摘录；直开出版社返回 429，PMC 直开出现验证页面，**出版社索引方法摘录级**。

- **问题与场景：** 多机农业数据采集与路径优化；论文模型假设固定飞行高度，优化水平方向；基准仿真为 200×200 米、3 架 UAV 和 15 个传感节点，并比较负载和规模变化。它不是对本项目三维独立目标城市避障的验证。
- **网络与机制：** CTDE，执行时各 Actor 取本地观测；**Transformer 编码器位于集中式 Critic**，按各机观测和动作形成 token，经注意力后输出联合价值；算法描述包含双 Critic。论文还涉及安全控制器触发状态及避碰/边界处理，不能当作本项目“只添加观测、不替换动作”的实现。
- **差异与局限：** 自注意力建模多机关系、Transformer 与 SAC 结合已存在，不可单独声称新颖。该文任务包含数据采集，超出本项目研究范围；不能据此引入通信或采集目标。其表示和计算量是容量、时延对照的理由，不是扩大网络必然改善导航的证据。

### Zhao 等，Multi-UAV Path Planning and Following Based on Multi-Agent Reinforcement Learning，Drones，2024

**来源与等级：** [出版社论文](https://www.mdpi.com/2504-446X/8/1/18)，DOI [10.3390/drones8010018](https://doi.org/10.3390/drones8010018)。已阅读出版社索引的第 2.2–2.4、3.1–3.2 节摘录；本次直开出版社返回 429，**出版社索引方法摘录级**。

- **任务、网络：** LiDAR、目标相对位置、速度和路径跟踪点作为观测；Actor 两层各 256，Q1/Q2 双网络的前两层各 256。文章通过参数共享和共享个体经验训练，多机把邻机当环境的一部分，并不等同于本项目的集中式团队 Q。
- **机制、场景：** 使用 AIT* 预先生成路径并更新跟踪点；奖励另含移动激励，用于应对初始静止与近目标过度谨慎。ROS/RViz 仿真以三机、20×20 米平面任务和圆柱障碍为例，策略输出速度类控制。
- **区别与局限：** 采样规划器引导、参数共享、近目标移动奖励均是已有研究；该论文配置和动作并非此处三维受限加速度任务，不能用其结果证明本项目基线表现或动力学安全。全文实时部署与更复杂三维、多机动态交会的范围需另核，不声称已复现。

### DCRP-ASAC — A UAV Path Planning Method Based on Deep Reinforcement Learning With Dense Rewards

**来源与等级：** [IEEE 论文页面](https://doi.org/10.1109/OJVT.2025.3642719)，DOI [10.1109/OJVT.2025.3642719](https://doi.org/10.1109/OJVT.2025.3642719)。查阅出版社索引中的模型、奖励与网络段；重定向后正文展示受限，**出版社索引方法摘录级**。

- **问题与机制：** 单机未知环境路径规划；用深度图和速度构造前向碰撞风险，并作为密集负奖励；Actor 包含跳连，另用从简单到复杂环境的迁移训练。
- **场景/局限：** AirSim 多旋翼和前向深度摄像头；策略输出速度及偏航类命令，由底层控制器执行。所读部分是单机而非 MASAC 多机联合导航，也不是显式 19 个加速度方向的可行控制集合。
- **与 V4 的区别：** 风险预测、速度/障碍距离结合以及课程迁移都已有先例；本项目候选拟把观测内可计算的有限方向预测作为策略风险先验，不把这一特征直接并入奖励。如果 Critic 也读取该特征，必须明确并控制其信息量。与其比较需控制动作接口、观测、计算量及环境，不能把单机结果移作多机证据。

## 2. 稀疏奖励与重采样：工程对照，不是核心创新

### Hindsight Experience Replay — Andrychowicz 等，NeurIPS，2017

**来源与等级：** [会议原论文页](https://papers.nips.cc/paper_files/paper/2017/hash/453fadbd8a1a3af50a9df4df899537b5-Abstract.html)，[预印本及 arXiv DOI](https://doi.org/10.48550/arXiv.1707.01495)。阅读摘要与方法基本定义，**原文部分级**。

- **问题/机制/实验：** 对目标条件化的离策略算法，把已发生的结果用于重标目标，使失败经验也形成针对替代目标的训练样本；论文场景是机械臂推、滑及抓取，不是多机路径规划。
- **应用边界：** HER 是已有采样/目标重标方法，不能作为 V4 候选创新，也不包含在本轮 Critic 采样 A/B。若以后单独实验，必须按重标目标重新计算所有目标相关观测、奖励和成功终止，并保留实际碰撞；三机联合目标应检查同一时刻满足所有位置及速度条件，不能把三个不同时刻的单机到达伪造成联合成功。以上是对本项目实现的推论，非原论文对本任务的实验结论。

### Potential-Based Reward Shaping — Ng、Harada、Russell，ICML，1999

**来源与等级：** [作者原论文 PDF](https://ai.stanford.edu/~ang/papers/shaping-icml99.pdf)。未核得该会议论文 DOI；不虚构。已读摘要、定义及定理，**原文部分级**。

- **问题/机制：** 在论文给定 MDP 条件下，以势函数构造转移奖励 \(F(s,a,s')=\gamma\Phi(s')-\Phi(s)\)，给出策略不变条件；论文也举出奖励设计导致循环的例子。
- **网络/场景/局限：** 这是奖励变换理论，不指定 MASAC 网络、UAV 场景或近目标减速方案。有限时域终止和吸收态的势函数处理必须单独核对；不能把单智能体理论直接说成部分可观测多机、函数逼近、熵正则训练的性能保证。
- **V3 计算核对：** V3 距离进展项是 \((d_t-d_{t+1})/2\)。若取 \(\Phi=-d/2\)、\(\gamma=0.99\)，标准 PBRS 为 \((d_t-0.99d_{t+1})/2\)，两者不相等。这仅说明该项不等于**此选择**的折扣势函数形式，并不单独证明实现错误、训练失败原因或不存在其他势函数。奖励更改若要研究须单独冻结，不得混入重采样诊断。

### Prioritized Experience Replay — Schaul 等，ICLR，2016

**来源与等级：** [原始论文](https://arxiv.org/abs/1511.05952)，[预印本 DOI 10.48550/arXiv.1511.05952](https://doi.org/10.48550/arXiv.1511.05952)。阅读摘要与采样/重要性加权方法，**原文部分级**。

- **机制与场景：** 按优先级非均匀重放并用重要性采样修正偏差，原文实证针对 DQN/Atari；不能直接断言适用于当前连续动作多机 SAC。
- **对 V4 A/B 的含义：** 优先回放和终止样本分层重采样均是工程诊断而非论文新贡献。若 buffer 大小为 \(N\)、样本实际概率为 \(p_i\)，以目标均匀分布定义时可采用 \(w_i=1/(Np_i)\)；固定每类抽样数量时必须按实际分层采样概率推导并记录。空层、放回方式、权重截断或批内归一化都会改变估计；即使未裁剪损失梯度的期望匹配，梯度范数裁剪与 Adam 是非线性的，也不能推断参数更新逐步无偏。Actor/alpha 与 Critic 抽样分开对照，记录终止比例与计算成本。

## 3. 架构和机动风险相关一手研究

### SAC 与 CTDE 的基础

- **SAC：** Haarnoja 等，ICML 2018，[会议原文](https://proceedings.mlr.press/v80/haarnoja18b.html)，[预印本 DOI 10.48550/arXiv.1801.01290](https://doi.org/10.48550/arXiv.1801.01290)。原文提出离策略、最大熵的连续控制 Actor–Critic；**原文摘要/算法级**。熵正则和随机策略是既有基础，不能作为 V4 创新；原文控制基准不构成本任务多机避障结论。
- **MADDPG/CTDE：** Lowe 等，NeurIPS 2017，[会议原文](https://papers.nips.cc/paper_files/paper/2017/hash/68a9750337a418a86fe06c1991a1d64c-Abstract.html)，[预印本 DOI 10.48550/arXiv.1706.02275](https://doi.org/10.48550/arXiv.1706.02275)。集中训练可利用其他代理信息，执行策略需核实自己的可用输入；**原文摘要级**。CTDE 不等于 Actor 可访问未来状态，也不等于每种实现均有集中团队 Q。

### Actor-Attention-Critic — Iqbal、Sha，ICML，2019

**来源与等级：** [PMLR 原论文](https://proceedings.mlr.press/v97/iqbal19a.html)，[预印本 DOI 10.48550/arXiv.1810.02912](https://doi.org/10.48550/arXiv.1810.02912)。阅读摘要和训练补充说明，**原文部分级**。方法将注意力用于集中式 Critic 选择其他代理的信息，执行策略分散；原文实验不是本项目任务。注意力不能作为新颖性单独主张；若 V4 探索对象 attention，必须与参数量、观测、预算匹配的 pooling 对照并报告推理成本。

### AVO — van den Berg 等，ICRA，2011

**来源与等级：** [作者项目/原论文](https://gamma-web.iacs.umd.edu/AVO/)，DOI [10.1109/ICRA.2011.5980408](https://doi.org/10.1109/ICRA.2011.5980408)。阅读原文摘要和作者项目说明，**原文部分级**。

- 研究受加速度约束的移动机器人与移动障碍/其他机器人避碰，分析可达到的速度集合并使用互惠假设。它不是 MASAC 多机三维学习方案，但直接说明“考虑加速度约束”和“预测避碰”已有先例。

### SCOPE — Chen 等，IJCAI，2026

**来源与等级：** [IJCAI 原论文及方法页面](https://ijcai.org/proceedings/2026/7)，DOI [10.24963/ijcai.2026/7](https://doi.org/10.24963/ijcai.2026/7)。已读摘要及方法概述，**原文部分级**。

## 4. 当前可检验主张与实验门槛

候选主张仅为：在相同本地观测和动作约束下，向量化的有限方向风险估计是否帮助学习多机三维独立目标导航。它仍可能是已有动力学预测和风险特征的组合；仅凭特征构造或短烟测不能声称创新、提升或安全。

建立 Standard MASAC 的 L0 导航能力后，才冻结机制对照：完整动态预测、仅静态预测、方向打乱/失配和无预测的匹配容量对照；同时控制训练预算、种子、奖励、可观测信息和动作接口，报告特征构造及 Actor 总时延。候选 2 秒离散预览只评价所采样的轨迹、已观测障碍和指定邻机预测；在 10 m/s、4 m/s² 条件下理论静态刹停时间约 2.5 秒，故不覆盖整个满速制动过程。方向打乱若无影响、错误动力学仍无损或额外成本抵消收益，均应作为对主张不利的结果保留。

网络 attention 和扩大容量是独立表示研究；参考规划器、HER、奖励变化、采样加权是独立工程/诊断变量。不得和候选特征同时改动后归功于一个“新方法”。训练种子才是独立重复单位；旧六图属于开发集，最终确认仍需与开发选择严格隔离。
