# Structured V3 方法规格与可证伪主张

2026-11-02。此文描述当前实现和后续应检验的主张，不表示候选创新或性能已经成立。当前只运行冻结的标准 MASAC 预算延长，见 [诊断协议](MASAC_V3_DIAGNOSTIC_PLAN.md)。

## 任务、动作与奖励

N 架无人机分别到达各自目标，控制周期 Δt=0.2 秒，环境上限 350 步。无人机是半径 1 米、带速度/加速度范数限制的离散运动模型，不是完整飞行动力学。Actor 输出原始动作 u∈(−1,1)³，环境执行：

\[
\bar u=\frac{u}{\max(1,\|u\|_2)},\qquad
v_{t+1}=\operatorname{proj}_{\|v\|\le v_{max}}(v_t+\Delta t\,a_{max}\bar u),\qquad
p_{t+1}=p_t+\Delta t\,v_{t+1}.
\]

Critic 读取原始 u。熵计算在 tanh 后、径向限制前；由于径向限制不是一一映射，不能将其称为执行加速度的精确熵。这是所有组共有的动作定义。

团队奖励为逐机奖励均值：距离减少量的一半、−0.02 时间成本、−0.002‖a_exec‖² 控制成本，以及目标捕获状态变化的 ±5；碰撞全队减 20，全队成功加 20。目标条件为距离小于 4 米且速度小于 2 m/s，并须全队同时满足。达到目标不冻结位置或违反加速度约束。

碰撞/成功终止不 bootstrap；350 步限制按 truncation 继续 bootstrap。这是当前训练语义，不能声称学到了显式剩余时间约束；观测中没有倒计时。所有候选组保持相同奖励和终止规则。

## 观测与网络：精确到张量接口

| 分支 | 每机原始输入 | 编码输出 | 备注 |
|---|---|---|---|
| 自身 | 20 | 64 | 目标相对位置、速度、前次执行加速度、位置/边界坐标、vmax、amax；坐标存在代数冗余 |
| 邻机 | 5×7 | 64 | 相对位置/速度与 mask；共享 6→32→32 后 masked mean/max |
| 最近建筑 | 8×7 | 64 | 相对中心、半尺寸与 mask；共享 6→32→32 后 masked mean/max |
| 动态障碍 | 4×8 | 64 | 相对位置/速度、半径与 mask；共享 7→32→32 后 masked mean/max |
| 机制通道 | 19 | 32 | 19→32→32；方向顺序保留 |
| 融合 | 288 | 128 | 288→128→128，ReLU；独立 μ/log_std 三维输出 |

**共享 Actor：65,350 参数。** 对象编码器合计 11,072，融合层 53,504，两个输出头合计 774。每机使用相同参数，去中心化推理；这不是 GNN 或注意力网络。

**每个团队 Critic：97,985 参数。** 独立集合编码器 11,072；对每机拼接 288 维编码和 3 维原始动作，经 291→128→128，共 53,888；在机维做 mean/max 拼成 256，经 256→128→1，共 33,025。两个 Critic 合计 195,970，目标双 Critic 另复制一份。Actor 与 Critic 不共享编码器权重。

联合输入形状为 (batch,N,162)/(batch,N,3)。团队 Q 对机的同步排列不变，Actor 对对象槽排列不敏感。接口支持 3/4/6 架；当前学习仅用三架，规模迁移尚无训练效果证据。Critic 读取整队局部观测，**没有完整地图的特权输入**。

## 实际优化目标

令 \(\ell=\frac1N\sum_i\log\pi_\theta(u_i|o_i)\) 为逐机 log probability 的均值，\(r\) 为团队均值奖励。两个目标 Q 构造：

\[
y=r+\gamma(1-d)\left[\min_{j=1,2}Q_{\bar\phi_j}(o',u')-\alpha\ell'\right],
\quad u'\sim\pi_\theta(\cdot|o').
\]

\[
L_Q=\sum_{j=1,2}\mathbb E[(Q_{\phi_j}(o,u)-y)^2],\qquad
L_\pi=\mathbb E[\alpha\ell-\min_j Q_{\phi_j}(o,u)].
\]

温度损失为 \(-\mathbb E[\log\alpha(\ell-3)]\)，即每机目标熵 −3。使用团队平均而非联合 log probability 总和，等价于固定 N 下对联合熵缩放，避免熵项随机数线性增大；不同 N 的有效性仍须评估。γ=0.99，τ=0.005，Adam 学习率 3e−4，每采样一个联合 transition 更新一次，Actor/Critic 全局梯度范数均限制为 5。训练 Replay 容量 100,000、batch 128。这些数值在预算延长中均未改变。

这些是已有 SAC 的协作实现选择，不是创新主张。一手算法背景：[SAC 官方教学说明](https://spinningup.openai.com/en/latest/algorithms/sac.html)。

## 单一候选：方向对应的有限控制储备

固定零控制、六个轴向和十二个面对角控制，共十九个满足范数限制的探针。每个探针保持恒定，按同一受限速度更新向前模拟两秒。在当前最近八栋建筑、边界、邻机与运动障碍上取最小预测净空 m_k；邻机和动态障碍使用恒速外推。

\[
m_k=\min_{h\in\{0,\ldots,10\}}\min_{j\in\mathcal O_i}\;c_{ij}(p^{(k)}_{t+h},\hat p_{j,t+h}),
\qquad f_i=\operatorname{clip}([m_1,\ldots,m_{19}]/40,-1,1).
\]

当前机制通道进入 **Actor 和两个 Critic** 的各自编码器；不能把潜在收益全部归因于 Actor。若要定位贡献，后续须补 Actor-only/Critic-only 的同容量消融。

最值得验证的主张是：**在距离和匀速预测相近的状态下，显式方向控制储备能否让策略更早选择减速/绕行，并在低加速度或侧向出口被遮挡时减少失败？**

这没有增加新的传感信息：基础观测已含位置、速度、amax 和局部几何。候选是显式结构化计算是否有助于学习的问题，仍可能只是特征工程。AVO 已考虑加速度受限避碰，SCOPE 已结合预览与策略/执行修正，DGPPO 已研究输入约束；不主张首次考虑加速度或短时预测。

## 必须保留的几何与可观测性限制

- 探针是有限恒定控制集合；全为负不能证明不存在可行变控制轨迹。
- 净空按时间点采样，不能证明采样间不碰撞；预览两秒也不覆盖默认满速刹停时间。
- 预览建筑使用欧氏有符号距离减机体半径；终止检查使用半径膨胀 AABB 的连续线段检测，在角部更保守。两者不是完全等价的碰撞几何。
- 当前最近八栋建筑集合在两秒预览内固定，远处建筑不加入；动态反弹与其他智能体的实际加速并非恒速外推。
- 无记忆策略只看到局部对象集合，不能据此声称解决了任意复杂地图的全局规划。

本轮不在运行中修正这些定义。后续若统一几何、加入记忆或调整预览，都须单独版本、先记录动机，再对全部对照公平重跑。

## 对照与可证伪标准

| 对照 | 19 维通道 | 用途 |
|---|---|---|
| Standard | 全零 | 基础 MASAC |
| Distance | 当前最小净空重复十九次 | 隔离显式距离摘要 |
| CV prediction | 恒速两秒最小净空重复十九次 | 隔离速度预测 |
| Maneuver | 按方向排列的十九个 m_k | 检验控制余量结构 |

四组容量、奖励、训练步数与地图种子规则匹配。额外消融包括每次观测独立打乱方向对应关系、错误 amax 预测、Actor-only/Critic-only、探针/时长与推理开销敏感性。后续协议需先分配预算；本轮尚未运行这些效果对照。

若方向打乱后无损失，不能支持“方向结构有效”；若低 amax/出口受限场景没有相应改变，不能支持“机动约束是收益原因”；若增益只发生在开发六图，不能支持未见地图泛化。基线尚全失败时，不能用候选组偶然非零结果代替可靠比较。

主指标为每训练种子在未见地图上的全队成功率；碰撞类型、剩余目标距离需包含失败。路径长度和到达时间只在成功样本上报告时，必须同时列成功数，避免把提前撞毁造成的短轨迹称为高效。控制代价不是实测能耗。统计独立单位为训练种子，不是同一策略的测试回合；保留最后检查点与全部失败，不能只选择最好曲线。

时间成本必须拆分特征构造与 Actor 前向。已有 `inference_ms` 字段只计 Actor，不含十九方向预览，不能当作方法整体推理延迟。工程剖析入口：`scripts/profile_masac_v3_pipeline.py`。
